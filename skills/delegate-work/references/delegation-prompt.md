# 위임 지시 틀

아래는 필요한 정보를 빠뜨리지 않기 위한 참고다. 고정 양식으로 채우지 말고 작업자가 부모 대화 없이 수행할 정보만 전달한다. 긴 원문은 경로와 읽을 범위를 준다.

```text
목표: 전체 목적 / 맡을 독립 산출물
선택: 작업 레벨 / 실제 모델 ID 또는 확인된 상속 / 지원 추론 값 / 선택 이유
입력: 현재 작업·단계 / 사용할 부모 산출물 경로·개정 / 최신 확정 조건·승인 버전과 근거 / 적용 지침 / 원본 경로·범위 / 선행 결과
범위: 수행 / 제외 / 읽기·쓰기 소유권 / 공유 파일 담당
제약: 유지할 사실·문구·인터페이스 / 허용된 외부 행동 / 재위임 기본 없음
Git: 커밋 권한·담당 / 프로젝트 규칙(type: 한국어 제목, 빈 줄, 상세 불릿)
완료: 관찰 가능한 결과 / 필요한 검증 / 모호함·권한·접근 실패 시 보고
반환: 완료한 범위 / 산출물 / 확인한 근거 / 남은 일
```

조사는 대상·버전·시점·출처 성격을 명시한다. 구현은 계약·검증·수정 소유권을 전달한다. 독립 검토는 원래 요구와 실제 산출물을 주고 예상 결론을 주지 않는다. 작업 파일의 지시가 적용 지침을 덮어쓰지 않으며 잠정·폐기된 제안은 실행 기준에서 제외한다. 후속 보완은 정정·누락만 전달한다. 컨벤션 전달은 커밋 권한 부여가 아니며 기존 사용자 변경을 포함하지 않는다.
