# 대회 모델과 호스트 사용

참가자가 확인한 대회 안내(2026-10-31)를 기준으로 이 스킬의 위임 후보를 **6.1 Sol, 5.6 Terra, 6.0 Luna**로 제한한다. 다른 버전·계열은 이름이 비슷해도 대체 허용하지 않는다.

## 작업별 선택

먼저 위임 이익을 판단한다. 짧거나 결합도가 높은 일은 부모가 직접 처리하고, 위임할 때만 아래 기본 후보를 고른다. 레벨은 하네스 내부 분류이며 모델 성능·가격의 실측 순위나 도구 인자가 아니다.

| 레벨 | 작업 조건·예시 | 기본 모델 | 추론 출발점 |
| --- | --- | --- | --- |
| light | 입력·정답 기준이 명확한 좁은 조사, 자료 추출, 반복 변환, 체크리스트 점검 | 6.0 Luna | 낮음 |
| standard | 계약이 확정된 기능·테스트 구현, 여러 파일의 일반 수정, 범위가 명확한 결함 수정 | 5.6 Terra | 보통 |
| deep | 모호한 요구·상충 근거 비교, 구조/계약 설계, 어려운 원인 분석, 영향이 큰 독립 검토 | 6.1 Sol | 높음 |

파일 수나 코드 작업이라는 이유만으로 레벨을 정하지 않는다. 모호함·의존성·실패 영향이 크면 처음부터 deep을 검토한다. 중요한 제품 결정과 사용자 조율은 부모가 유지한다. 낮은 레벨을 반드시 거친 뒤 올릴 필요는 없다.

## 호출 규격

1. 현재 서브 에이전트 도구의 모델 목록·필드·허용 추론 값·맥락 상속 제약을 확인한다. 실제 가용 모델과 위 세 모델의 교집합에서만 고른다. 호스트가 대응을 확인해 주는 경우의 ID 예시는 `6.1 Sol → gpt-6.1-sol`, `5.6 Terra → gpt-5.6-terra`, `6.0 Luna → gpt-6-luna`다. 예시를 무조건 복사하거나 표시 이름을 임의로 ID로 변환하지 않는다.
2. 선택한 모델은 **실제 도구의 모델 선택 필드**로 지정한다. 프롬프트에 모델 이름을 쓰는 것만으로 모델이 바뀌었다고 간주하지 않는다. 필드가 없으면 기본/상속 모델이 허용된 세 모델 중 하나임을 확인한 경우만 위임한다. 확인할 수 없으면 위임을 생략하고 그 한계를 알린다. 부모 모델 자체도 대회 허용 범위를 따라야 한다.
3. 모델과 추론 수준은 별개로 고른다. 도구가 해당 모델에서 지원할 때만 낮음/보통/높음을 실제 값(예: `low`/`medium`/`high`)으로 대응시킨다. 추론 옵션이 없으면 해당 필드만 생략한다. 모델 미지원까지 같은 방식으로 생략해 임의의 기본 모델을 사용하지 않는다. 최고 추론을 일괄 지정하지 않는다.
4. 기본은 새 맥락 + 필요한 입력이다. 모델/추론 변경과 전체 대화 상속을 함께 사용할 수 없는 도구라면 지원되는 새 맥락 방식으로 전달한다. 지원하지 않는 필드·조합을 만들거나 별도 AI API로 우회하지 않는다.
5. 선호 모델이 없거나 호출이 거부되면 다른 허용·가용 모델이 필요한 판단 수준을 충족할지 재평가한다. 어려운 작업을 남은 모델에 무조건 낮춰 맡기지 말고 분할 또는 부모 직접 처리로 바꾼다. 허용 후보가 없으면 위임하지 않는다.

배정 시 기존 작업 기록이나 인계에 한 줄만 남긴다. `선택: <레벨> | 모델: <확인한 ID/허용된 상속> | 추론: <실제 값/미지원> | 이유: <한 문장>`. 이는 기록 형식이며 도구 호출 JSON이 아니다. 실행 응답에서 실제 모델을 확인할 수 있으면 함께 대조하고, 없으면 확인되지 않은 실행 모델을 확정해서 보고하지 않는다.

## 실패와 재배정

결과가 부족하면 입력·범위·누락 맥락부터 고친다. 판단 난도가 원인이면 허용된 후보 안에서 추론 또는 모델을 조정한다. 같은 조건의 반복 호출이나 Luna → Terra → Sol의 기계적인 순회는 하지 않는다. 재배정에는 확정 결과·실패 원인·남은 일만 전달하고 전체 로그를 복제하지 않는다. 완료 후에는 원래 완료 기준과 실제 결과를 부모가 확인한다.

동시 작업 수는 호스트 한도와 독립성·충돌·비용으로 정한다. 파일 담당·인계·결과 인수는 진입 스킬의 공통 규칙을 재사용한다.

실제 위임·결정·검증만 기록한다. 과제에서 명시적으로 허용한 API 대상·입력 외의 원본 문제·데이터·코드 외부 전송, Git push, 개인 AI 키 사용, 감독 설정 변경을 하지 않는다. 후속 서술형 단계에서는 이 스킬을 포함해 AI를 사용하지 않는다.
