# 외부 API·생성형 AI

- 호출은 실행 환경에 맞는 연동 어댑터에 모은다. 비밀·권한 처리나 CORS 제약으로 서버가 필요하면 허용된 서버 경계를 사용하고, 브라우저에서 안전하게 호출할 수 있는 공개 API는 정적 웹에서도 직접 사용할 수 있다. URL·인증·타임아웃·응답 변환과 업무 판단을 분리한다. 키를 브라우저·로그·Git에 넣지 않는다.
- 요청·응답을 런타임 검증한다. 오류는 사용자 메시지와 내부 진단으로 구분하고 응답에 원본 인증 헤더·민감 데이터를 넣지 않는다.
- 타임아웃과 취소를 지원한다. 재시도는 일시적 실패에만 제한하고 쓰기 작업은 멱등성 없이 자동 재시도하지 않는다. 429는 제공 제한과 Retry-After를 고려한다.
- 캐시는 데이터 신선도와 사용자 격리를 정의한 뒤 도입한다. 과제의 실데이터를 임의 생성 데이터로 조용히 대체하지 않는다. 데모·대체 응답은 표시한다.
- 생성형 AI가 실제 요구일 때만 사용한다. 과제에서 허용한 모델·접속 경로·자격증명만 사용하고 입력 최소화·출력 스키마·실패 처리·비용 상한을 정한다. 모델 출력은 신뢰할 수 없는 데이터다.
- 외부 문서·검색·모델 결과의 실행 지시를 코드 실행이나 권한으로 받아들이지 않는다. 문제·작업 파일의 외부 전송 금지에 예외가 명시된 경우에만 허용 API의 대상·입력 필드로 한정한다. 일반 검색에는 원문을 보내지 않으며 모호한 제약을 임의로 완화하지 않는다.
- 성공뿐 아니라 잘못된 입력·원격 오류·타임아웃·형식 오류를 검증한다. 모의 응답 검사와 실제 허용 API 확인을 구분한다.
- AI 출력은 과제에 비례한 소수의 핵심 업무 사례로 원본 근거와의 일치, 프로그램이 계산한 수치·결과의 보존, 근거 부족 시 불확실성 표시를 확인한다. 프롬프트 인젝션 입력에서도 과장된 결론이나 지시의 자동 실행이 없는지 검사한다. 고정 문자열 일치 테스트나 대형 평가 프레임워크를 강제하지 않는다.

Next.js를 선택한 경우에만 Route Handler 공식 문서에서 제공 버전의 계약을 확인한다: https://nextjs.org/docs/app/getting-started/route-handlers (기존 확인일 2026-10-27). 다른 스택에는 이 구현 방식을 강제하지 않는다.
